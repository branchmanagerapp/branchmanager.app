🌳 How We Work — the Branch Manager workflow

One system, three people: Doug, Catherine, Claude. Everything lives in branchmanager.app. Updated July 9, 2026.

The one rule

If it happened, it goes in Branch Manager — same day, from your phone. Visited a job? Update the quote. Finished work? Mark the job done. Got paid? Mark it paid. The app is only as smart as what we tell it. When the statuses are true, the Today board runs the whole business by itself.

Daily worksheet — morning (5 minutes, in the app)

  1. Open branchmanager.app → the Today board is the homepage. It lists by name: Send these · Invoices to send · Collect · Write the estimate · Waiting to hear back · Approved—schedule it · Changes requested · This week's jobs.
  2. Work top to bottom. Send-these and Invoices first (that's money sitting still). Tap a row — it opens the record.
  3. Anything new from calls/texts overnight? Create the client + a $0 draft quote right then (30 seconds). It'll show under "Write the estimate" until priced.

Field rules — during the day

  • Gave a price on-site? Put it in the quote before you drive away. Photos: tap 📸+ in the quote → pick all photos → tap each onto its tree.
  • Finished a job? Mark it completed → tap "convert to invoice." A done job that isn't invoiced is invisible money.
  • Customer said yes by text/phone? Flip the quote to Approved yourself — don't wait for the link click.
  • Never share a quote link from a draft. Use the green Send button — it makes the link live and stamps it sent.

Where Claude sits (so you can't break it from the back end)

Claude works through the same cloud API the app itself uses, as the owner account — every change Claude makes shows up in the app instantly, exactly as if it was typed in. Nothing bypasses the app's rules: drafts stay drafts, tax defaults apply, customer sends stay human-only. You don't need to touch Supabase or the database — if something looks wrong in the app, say it in chat and Claude fixes the record; that's the supported path. The back end is Claude's job now.

If a quote "reverts" or a save doesn't stick: your phone is running an old cached version. Fully close and reopen the app; if it persists, delete the home-screen icon and re-add it from branchmanager.app. v984+ shows a red banner when a save fails — never ignore it.

Weekly (Fridays, 10 minutes)

  • Claude runs the audit: stale Sent quotes → follow-up list, unpaid invoices → Collect, duplicate/orphan records → cleaned.
  • Anything still in Jobber gets exported → Claude reconciles → BM stays the single source of truth until cutover.
📄 Want paper? The printable Today sheet still exists — but the app's Today board is the live one. The sheet is a snapshot; the board is the truth.
