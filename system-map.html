① How Branch Manager is built

The mental model in five lines.

Front end

A single-page app written in plain JavaScript (no framework). All the screens are src/pages/*.js modules bundled into one file dist/bm.bundle.vNNN.min.js. The shell + all CSS live in index.html. Used mobile-first, on phones, in the field.

Back end

Supabase — a hosted Postgres database (the 49 tables below) + file Storage (6 buckets) + serverless "edge functions" (the ~20 server jobs). The app talks to it with a public anon key, and Row-Level Security keeps each tenant's data isolated.

Data flow

Each device keeps a local copy (fast, works offline) and syncs to the cloud. The core pipeline: Request → Quote → Job → Invoice → Payment, each stage advancing the next.

Deploy

Fresh-clone the live repo → edit source → rebuild the bundle → bump the version in three places that must match (index.html BUNDLED_VERSION, the <script> filename, version.json) → push. Live in ~60s; devices auto-update when version.json climbs.

Phone / SMS

Dialpad, via the dialpad-sms-send edge function. Payments via Stripe. Email via Resend.

⑤ Code map — which function renders what

This is the part that stops the "edited the wrong thing" mistakes. There are often TWO renderers for the same data — the in-app view and the customer-facing email/PDF — and they are different code.

The gotcha that bit us: For a quote, quotes.js showDetail() is the in-app view Doug sees, and it draws line items via renderLineItems(). quotes.js _buildEmailHtml() is the separate customer email/PDF. Editing one does NOT change the other. Always trace from "what the user opens" to the code, not from a search hit.

Quotes — src/pages/quotes.js

render() = the list · showDetail(id) = in-app quote view (into the page) · renderLineItems(q,id) = the in-app line-item table (with + Add / delete / photos) · showForm(id) = the edit form · _buildEmailHtml(id) = the customer email/PDF · _getFiltered() = list sort/filter.

Invoices — src/pages/invoices.js

showDetail(id) = in-app invoice view · line items are a separate inline grid · _sendInvoiceEmail() stamps status=sent. Payments render via payments.js renderForInvoice().

Jobs — src/pages/jobs.js

render() list · showDetail(id) in-app job view · _textCrew() / _etaToClient() SMS.

Dashboard — src/pages/dashboard.js

"Today board" reads live from DB.jobs.getAll() filtered to today.

Sync & data — src/db.js, src/supacloud.js, src/supabase.js

Local-first store + cloud sync (anon key). Loud red banner on rejected saves; write-queue + tombstones.

Phone — src/dialpad.js

Dialpad.sendSMS() → the dialpad-sms-send edge fn. showTextModal() = the compose box.
