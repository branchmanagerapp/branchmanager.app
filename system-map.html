03 · SocialBranch rollout — one engine, three brands

Port what already works in BM into the other two apps.

SocialBranch is a self-contained module (src/pages/socialbranch.js) — post store + compose/calendar UI + a pluggable publish backend (Zapier/Make webhook today, GMB/Meta OAuth as it comes online). Same code, three isolated instances:

  • 🌳 Tree — done. Live in Branch Manager, managing peekskilltree posting (GMB + socials).
  • 🛹 Skate — port into skateOS. Its own post store + 2nd Nature Skate's IG/TikTok/FB. Feeds off the clip pipeline.
  • 🌱 Lawn — port into SmartLawn. Its own store + Smart Lawn's accounts. Feeds off install/demo clips + the map tool.

Separate post store + separate connected accounts per instance = a post structurally cannot cross brands. Each is modifiable independently (different networks, cadence, voice per the brand themes). Publishing stays draft → approve-batch → scheduled; nothing fires unapproved.
